## สรุป 6 ตัวเลือกหัวข้อสำหรับทีม

| ลำดับ | หัวข้อโปรเจกต์ | เทคนิคและเครื่องมือหลัก | จุดเด่นสำหรับการพัฒนา |
| :---: | :--- | :--- | :--- |
| 1 | **วิเคราะห์อารมณ์ข้อความภาษาไทย** | WangchanBERTa, Wisesight Dataset | มี Baseline ชัดเจน ทำ Product และวัดผลง่าย |
| 2 | **ตรวจสอบข่าวปลอมภาษาไทย** | IR + NLP + Ensemble Classifier | มีงานวิจัยและ Framework รองรับชัดเจน |
| 3 | **สรุปข่าวไทยอัตโนมัติ** | TextRank + mBART, ThaiSum | มี Dataset ขนาดใหญ่ พร้อมตัววัด ROUGE |
| 4 | **ตรวจคำผิดและไวยากรณ์ไทย** | CRF Baseline + Neural Seq2Seq | ต่อยอดเป็นปลั๊กอินหรือระบบตรวจเอกสารได้ |
| 5 | **แชทบอทตอบคำถามจากเอกสาร** | RAG + Thai LLM / Vector DB | ตรงเทรนด์ นำไป Deploy ใช้งานได้จริง |
| 6 | **ตัดคำและหา Entity เฉพาะโดเมน** | DeepCut / SynThai (Domain-specific) | เหมาะกับการศึกษาโครงสร้างภาษาเชิงลึก |

## ขั้นตอนการทำงานของทีม (Next Steps)

2. ประชุมทีมเพื่อสรุปข้อดี-ข้อจำกัด และโหวตเลือกหัวข้อที่เหมาะสมที่สุด 1 หัวข้อ
3. กำหนดและจัดสรรหน้าที่สำหรับสมาชิก 6–7 คน (Data & Baseline / NLP Specialist / Deployment / Pitching & QA)
4. สร้าง Development Repository แยกเพื่อเริ่มต้นพัฒนาโมเดลและชิ้นงานจริงต่อไป
